Constraints aren't the enemy of good design — they're the brief. A system that flips cleanly between light and dark was never an accident.

Ordered list

  1. Define the tokens first — they are the contract.
  2. Build components that consume only tokens.
  3. Let the theme switch do the rest.

Unordered list

  • Crimson accent, cool-grey neutrals.
  • Diagrams and code render as fixed light/dark islands.
  • Focus rings, selection colour, and markers all token-driven.

Code

A .vl-code block is a dark island in both themes. Syntax is hand-tagged with .vl-kw, .vl-st, .vl-fn, .vl-nm, .vl-nu, and .vl-cm.

# bound the agent before you trust it
from vibeloom import Agent, Sandbox

agent = Agent(
    model="claude-opus",
    max_steps=8,
    sandbox=Sandbox(network=False),
)

def run(task):
    return agent.solve(task, retries=2)

Figure + diagram

A .vl-figure is a light island in both themes. It carries a __head (title + __num), an inline SVG built from diagram primitives (.fill-*, .solid-*, .stroke-*, .edge, .edge-strong, .dg-t, .dg-ink, .dg-center), and a figcaption. Toggle the theme — the figure stays put.

Marks + charts

A .vl-chart is a horizontal chart drawn to scale from zero by its data: set --max on the chart and --v on each mark. Add --from to draw a from→to step (waterfalls, ranges). Rows are __label | __track; marks are __bar, __dot and __val; --y stacks two marks in one row. Modifiers: --grid (gridlines every --tick), --ref/--ref2 (dashed lines at --ref/--ref2), --band (shaded --b0–--b1). Charts are light islands: put them in a .vl-figure.

Fills come from one mark vocabulary used by every chart-like component: .vl-mark--1…6/--s (solid tokens), --hl (crimson: the subject), --ink, --soft (light fill: costs, a second series), --target (hollow, dashed: a target, never a result), --upside (hatched: not in the base case), and the shapes --sq/--dia.

Stacked bar + quadrant

.vl-stackbar: segments sized by --v against --max. Segments too narrow for their label take __seg--out (below) or __seg--above; __brackets groups segments.

.vl-quad: a 2×2 with ordinal axes (0–100). __ytick/__xtick name the tiers, __zone shades a region, __pt places a __dot (any mark) and its __lbl (__pt--l/--t/--b move the label), __note pins a short quote.

Slide + sheet additions

  • .vl-slide__source sits in .vl-slide__footer beside the page number: sentence case, muted, wraps to two lines.
  • .vl-slide__notes is hidden on screen. On a deck with .vl-deck--handout, print puts each slide on a 1440×1080 page with its note in a band beneath (the read-alone PDF). Plain decks print one 1440×900 page per slide.
  • .vl-slide--dense (smaller title, tighter padding) and .vl-slide--wide (lifts the 880px cap) fit an assertion, a visual and a source on one 1440×900 slide; .vl-slide__cols--3-2/--2-3 weight a split, --mid centres it.
  • .vl-sheet is a single printable page: __cols flows blocks column-major in two columns (one at ≤900px), __span crosses both, __fine is fine print. Print: US Letter, content 7.27 × 10.0in (fits A4 too), body 9pt, fine 6.5pt.
  • Print always uses the light theme; figures and charts stay light islands in dark mode.
